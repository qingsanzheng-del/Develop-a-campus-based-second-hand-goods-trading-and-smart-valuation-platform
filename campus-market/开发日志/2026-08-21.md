## 遇到的问题 / 备注

- AI 后端已从云端 DashScope 切换为**本地 Ollama `qwen3.5:4b`**（视觉多模态，免 API Key，离线免费），`.env` 的 `AI_PROVIDER=ollama` 即默认；如需切回云端改 `AI_PROVIDER=dashscope` 并填 `DASHSCOPE_API_KEY` 即可。
- 小模型 JSON 输出偶发不稳定，已用「强制 JSON + 尾逗号清理 + 3 次重试」覆盖。
- 纯色无对象的测试图会让模型返回「图片无效请补全描述」，属正常——真实商品照片 + 补充说明可稳定识别（实测红色布料图返回「95新、8-20 元、生活用品」）。
- `AnalyzeOut.copy` 字段名与 Pydantic `BaseModel.copy()` 同名，仅触发一条无害告警，序列化输出已验证正确，暂不改动避免引入风险。
