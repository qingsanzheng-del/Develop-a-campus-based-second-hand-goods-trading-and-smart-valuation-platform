# 校园二手交易与智能估价平台 — 项目开发指引

本项目是一款校园二手交易 + 智能估价的全栈应用，技术栈：**Vue 3 + Tailwind CSS / FastAPI / SQLite / 本地 Ollama `qwen3.5:4b`（视觉多模态，云端 DashScope Qwen-VL 可切换）**。

## 工作说明

1. **增量推进**：严格按 [docs/06-执行步骤.md](docs/06-执行步骤.md) 的里程碑顺序推进，每个里程碑完成后**运行验证**再进入下一个，不要一次性堆砌大量未验证代码。
2. **开发日志**：每个开发会话结束前，更新或创建 `开发日志/YYYY-MM-DD.md`，记录「今日完成」与「待办事项」（参考 `开发日志/_模板.md`）。
3. **安全规范**：`DASHSCOPE_API_KEY`、`JWT_SECRET` 等密钥只存在于 `backend/.env`，**严禁**写进前端代码或提交到仓库；`.env` 已在 `.gitignore` 中排除。
4. **代码风格**：后端遵循 FastAPI + SQLAlchemy 惯例；前端遵循 Vue 3 组合式 API（`<script setup>`）；全站 UI 统一使用 `brand` 淡蓝主题色（见 [docs/03-设计规范.md](docs/03-设计规范.md)）。
5. **验证优先**：改动后端后运行 uvicorn 确认无报错；改动前端后运行 `npm run dev` 确认能启动；关键闭环（发品 → 入库 → 首页 → 检索 → 状态流转）需按 [docs/07-测试验收.md](docs/07-测试验收.md) 手动走查。
