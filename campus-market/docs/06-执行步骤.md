# 执行步骤（分里程碑）

> 原则：**小步推进，每步验证**。每个里程碑完成后运行验证再进入下一个。

| 里程碑 | 内容 | 验证方式 |
|--------|------|----------|
| M0 项目骨架 | 目录结构、docs/、开发日志/、CLAUDE.md、.gitignore | 文件齐全 |
| M1 后端基础 + 鉴权 | config/database/models/schemas + JWT 注册登录 + admin seed + main.py | uvicorn 启动；/docs 可访问；curl 注册/登录成功 |
| M2 AI 估价 | ai.py（Qwen-VL）+ `POST /api/ai/analyze` | 传真实图，返回分类/成色/价格/文案 |
| M3 商品 + 合规 | moderation + listings/admin 路由（发布/列表/详情/状态/我的/管理） | curl 全接口走查 |
| M4 前端骨架 | Vite + Vue3 + Tailwind v4 主题 + Router + Pinia + axios | `npm run dev` 启动 |
| M5 前端页面 | 登录注册 → 发布 → 首页 → 详情 → 个人中心 → 管理 | 浏览器走查 |
| M6 打磨 + 交付 | 骨架屏/加载动效/错误拦截 + README + 录屏走查 | 端到端闭环（见 07-测试验收） |

## 启动命令

```bash
# 后端
cd backend
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt
# 配置 .env（DASHSCOPE_API_KEY）
.venv/Scripts/python -m uvicorn app.main:app --reload --port 8000

# 前端
cd frontend
npm install
npm run dev
```
