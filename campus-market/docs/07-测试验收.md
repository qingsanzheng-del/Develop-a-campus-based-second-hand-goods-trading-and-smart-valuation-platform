# 测试验收

## 端到端闭环走查

1. 启动后端（8000）与前端（dev），打开 `http://localhost:5173`。
2. **注册/登录**：注册新账号 → 自动登录。
3. **AI 发品**：进入发布页 → 上传 1–3 张真实物品图 + 补充说明 → 点「AI 智能估价」→ 出现加载动效/骨架屏 → 得到可编辑草稿 → 微调 → 填联系方式 → 发布。
4. **入库**：发布成功跳转，确认数据已写入 SQLite（可用 `/docs` 或浏览器刷新验证）。
5. **首页检索**：首页出现该卡片 → 分类 tab 切换过滤 → 关键词搜索命中。
6. **详情**：点卡片进详情 → 大图/标签/文案/时间 → 一键复制联系方式。
7. **状态流转**：标记「已售出」→ 首页卡片变灰 + 已售角标；标记「下架」→ 首页消失。
8. **个人中心**：查看「我发布的」物品，进行状态操作。
9. **管理员**：admin 登录 → 管理页下架/删除某条 → 首页对应卡片消失。

## 合规闭环

- 发布含敏感词的标题 → 商品进入 `pending` 待审核，不出现在首页 → admin 在管理页「通过」或「下架」。

## 验收标准（对照评分）

- [ ] 基础分：全流程无报错跑通。
- [ ] 进阶分：上传/AI 请求有加载动效 + 骨架屏，无界面错位；API Key 未硬编码在前端（仅后端 `.env`）；接口有异常拦截与错误提示。
- [ ] 加分项：JWT 登录 + 个人中心；管理员合规管控（敏感词 + 违规图 + 下架删除）。

## 录屏脚本（30s–1min）

上传图片 → AI 估价 → 发布入库 → 首页检索过滤 → 详情复制 → 状态流转。
