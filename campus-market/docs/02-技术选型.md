# 技术选型

| 层 | 选型 | 版本/说明 |
|----|------|-----------|
| 前端框架 | Vue 3（组合式 API） | `<script setup>` |
| 前端构建 | Vite | 开发服务器 + 生产构建 |
| 样式 | Tailwind CSS v4 | `@tailwindcss/vite` 插件，CSS-first 主题配置 |
| 路由 / 状态 | Vue Router + Pinia | 页面路由 + 登录态管理 |
| HTTP 客户端 | axios | 拦截器统一注入 token / 处理错误 |
| 后端框架 | FastAPI | 自动生成 `/docs` 接口文档 |
| ORM | SQLAlchemy 2.0 | 声明式模型 |
| 数据库 | SQLite | 单文件 `backend/app.db` |
| AI 能力（默认） | 本地 Ollama `qwen3.5:4b`（视觉多模态） | 免费、离线、免 API Key |
| AI 能力（可选） | 通义千问 Qwen-VL | 阿里云 DashScope，OpenAI 兼容接口 |
| AI 调用方式 | openai SDK | Ollama：`base_url=http://localhost:11434/v1`；DashScope：`https://dashscope.aliyuncs.com/compatible-mode/v1`，图片 base64 data URL |
| 鉴权 | PyJWT + bcrypt | JWT 存 localStorage，后端环境变量读密钥 |

## 关键设计决策

- **AI 发品两步走**：`POST /api/ai/analyze` 先出草稿（不写库）→ 用户微调 → `POST /api/listings` 写库，匹配「AI 生成 → 微调 → 发布」流程。
- **图片存储**：图片落盘 `backend/uploads/`，数据库存相对路径 JSON 数组（1–3 张）。
- **合规过滤**：本地敏感词表 + Qwen-VL 违规图审核，违规则商品进入 `pending` 待审核，不出现在前台。
- **密钥安全**：`DASHSCOPE_API_KEY`、`JWT_SECRET` 只存后端 `.env`，前端零硬编码。
