# 数据库设计（SQLite）

文件：`backend/app.db`（SQLAlchemy 建表，`backend/app/models.py`）。

## users

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer PK | 用户唯一标识 |
| username | String(50) unique | 用户名 |
| password_hash | String(255) | bcrypt 哈希 |
| role | String(20) | `user` / `admin` |
| created_at | DateTime | 注册时间 |

## listings（对齐作业「至少包含」字段清单）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer PK | 商品唯一标识 |
| title | String(120) | 商品标题 |
| category | String(30) index | 数码/书籍/生活用品/服饰鞋包/运动户外/其他 |
| description | Text | 用户一句话补充 |
| images | JSON | 图片相对路径数组（`/uploads/xx.jpg`，1–3 张） |
| ai_condition | String(30) | AI 成色等级（如「9成新」） |
| ai_tags | JSON | AI 评估标签数组（如 ["9成新","高性价比"]） |
| ai_copy | Text | AI 营销文案 |
| price_min / price_max | Float | AI 推荐价格区间 |
| contact | String(100) | 卖家联系方式 |
| status | String(20) index | `active` / `sold` / `delisted` / `pending` |
| is_flagged | Boolean | 是否命中违规过滤 |
| seller_id | Integer FK→users | 发布者 |
| created_at / updated_at | DateTime | 发布时间 / 更新时间 |

## 状态说明

- `active`：在售（前台展示）
- `sold`：已售出（前台展示 + 已售角标）
- `delisted`：已下架（前台不展示）
- `pending`：命中敏感词/违规图，待管理员审核（前台不展示）
