# 设计规范（UI）

## 总体风格

简洁、直观、轻量。卡片式布局，圆角、留白充足、阴影克制，信息层级清晰。

## 主题色（淡蓝 brand 色阶）

在 `frontend/src/style.css` 的 `@theme` 中定义 `brand` 色阶（基于淡蓝/sky 系）：

| Token | 色值 | 用途 |
|-------|------|------|
| brand-50 | #f0f9ff | 页面浅底 |
| brand-100 | #e0f2fe | 卡片浅底 / hover 态 |
| brand-200 | #bae6fd | 边框、选中底 |
| brand-400 | #38bdf8 | 图标、次要强调 |
| brand-500 | #0ea5e9 | 主色：主按钮、链接、高亮 |
| brand-600 | #0284c7 | 主色 hover、强调文字 |
| brand-700 | #0369a1 | 深色文字/图标 |

- 中性色用 Tailwind 内置 `slate`；成功/危险用 `emerald` / `rose`。
- 主按钮 `bg-brand-500 hover:bg-brand-600 text-white rounded-xl`。

## 布局

- 顶部导航栏：Logo + 平台名、导航链接、登录态用户菜单。
- 首页：分类 tab + 搜索框 + 卡片网格（响应式 `grid-cols-1 sm:2 lg:3 xl:4`）。
- 内容区最大宽度 `max-w-7xl mx-auto px-4`。

## 组件规范

- **商品卡片（ListingCard）**：封面图 + 标题 + 价格区间 + 成色标签 + 分类角标；已售出时整体降透明度并叠加「已售出」角标。
- **标签（TagBadge）**：圆角小徽章，浅色底 + 深色字。
- **骨架屏（SkeletonCard）**：加载中显示灰色占位块，避免布局跳动。
- **图片上传（ImageUploader）**：拖拽/点击上传，1–3 张，缩略图预览，超出提示。

## 交互与动效

- AI 估价期间：按钮加载态 + 文案「AI 正在识别商品…」+ 表单区域骨架屏。
- 复制联系方式：一键复制，成功后给出「已复制」反馈。
- 所有异步操作有 loading 与错误提示（toast）。
